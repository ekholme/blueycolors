# Available Bluey Color Palettes

Use
[`bluey_palette`](https://ekholme.github.io/blueycolors/reference/bluey_palette.md)
to extract palettes of the desired length

## Usage

``` r
bluey_colors
```

## Value

A named `list` of character vectors, where each vector contains hex
color codes corresponding to a Bluey character palette (`bluey`,
`chilli`, `heeler`, and `socks`).
